# RBTreeVisualization
It's a visualization of a red black tree. It isn't animated, and I just made it for school, but it should be correct!

**How do I run the program?**\
Simply click [here!](https://topazcat2425-dotcom.github.io/RBTreeVisualization/)

**How do I insert elements?**\
just input numbers into the input box, then press enter! or press the insert button!\
Ex: [5, 7, 200, 30, 20, 71]

**How do I remove elements?**\
Just click the "remove selected" to enter removal mode. Then simply click whichever node you wish to delete.

**How do I search elements?**\
With your eyes. If you press f12 to enter inspect element, switch over to the console tab and run the function findValue() and enter the value you wish to find in the tree. It will return the index of the value you wanted to find, or -1 if it doesn't exist.
